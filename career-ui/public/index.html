Normal flow

  1. SaveAdd an interesting job with status Saved. Company, role, and URL may be filled later.
  2. ReviewUse Ask Career-Ops for a full evaluation, or update the row yourself.
  3. PrepareChoose a baseline, an existing PDF, or ask Career-Ops to decide whether to reuse, edit, or regenerate.
  4. ApplySubmit the application yourself, then change the status to Applied and record the submission date.
  5. Follow upKeep updating status as replies, interviews, and outcomes arrive.

Resume choices

Baseline
Copies the selected baseline into the job's draft folder. Later revisions reuse that folder. Adding PDFs under local/resume-baselines/ adds options automatically.
Ask Career-Ops
Opens PowerShell with a job-specific prompt. Career-Ops decides between reuse, reuse with edits, or a new tailored resume.
Existing PDF
Links an already generated PDF from output/.
No resume
Leaves the row without a linked file.

Important behavior

Status changes
Never choose, copy, or generate a resume automatically.
Delete
Removes only the tracker row. Existing reports and resume files stay on disk.
