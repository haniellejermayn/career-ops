# Product

## Register

product

## Users

This fork is a personal job-search workspace for one user. The interface supports quick, local maintenance of one unified job tracker without requiring an AI conversation for routine data entry.

## Product Purpose

Provide a simple local interface for capturing jobs, updating their lifecycle, and linking the relevant resume while keeping Career-Ops Markdown files and canonical scripts as the source of truth. Success means the tracker feels as direct as a lightweight spreadsheet while retaining Career-Ops resume reasoning and scanner compatibility.

## Brand Personality

Calm, simple, professional. Familiar controls and restrained presentation should keep attention on the job-search workflow.

## Anti-references

Avoid dashboard metrics, permanent sidebars, excessive cards, decorative motion, dense configuration screens, and bespoke interaction patterns. Do not create a second database or an Obsidian-style note system that competes with Career-Ops data files.

## Design Principles

- Keep the existing Career-Ops data contract authoritative.
- Make routine capture and status work possible without an agent.
- Keep resume selection independent from application status.
- Discover baseline resumes dynamically instead of maintaining a second configuration list.
- Use one centered work surface with progressive disclosure for secondary actions.
- Show records before summaries; omit analytics unless they answer a current task.
- Prefer familiar forms, tables, filters, and direct links.
- Keep setup local, dependency-light, and easy to reverse.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus states, sufficient contrast, responsive layouts, clear validation messages, semantic HTML, and reduced-motion preferences.
